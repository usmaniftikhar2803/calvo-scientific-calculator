How to Use — Button Guide

A complete walkthrough of every button on Calvo's scientific calculator.

Calvo's calculator is modeled on a real scientific calculator (Casio-style), so every button has a main function printed on it, and many buttons also have a second (shift) function printed above them in a smaller color. This guide explains what every key does and how to access both functions.

Golden Rule: To use a key's normal (white) function, just tap it. To use a key's shift (upper) function, first tap the SHIFT key — the display will show a "SHIFT" indicator — then tap the key you want. For example, pressing SHIFT then √ gives you x² instead of the square root.

1. Mode & Control Keys

ButtonWhat it does
SHIFT Activates the second (upper) function of the next key you press. Tap it once, the SHIFT indicator lights up on screen, then tap any key to use its shift function.
ALPHA Switches into letter-input mode, used for storing values into memory variables (like A, B, C) and for the CALC/SOLVE features.
MODE Opens the calculator's mode/settings options (used to switch calculation settings).
ON Resets the calculator — clears the current calculation and starts fresh, similar to a power-on reset.
REPLAY (▲ / ▼) Moves the cursor left/right or up/down through a previous calculation so you can review or edit it before recalculating.
AC All Clear — wipes the entire screen and starts a brand-new calculation.
DEL Deletes the last character/digit you entered (like backspace).

2. Numbers & Basic Operations

ButtonWhat it does
0–9 Enter digits for your number.
. Adds a decimal point to enter fractional numbers (e.g. 3.14).
+ − × ÷ Basic arithmetic — addition, subtraction, multiplication and division.
(-) Enters a negative sign before a number (different from the subtraction key), e.g. (-)5 gives −5.
( ) Open and close brackets, used to control the order of operations in longer expressions.
= Calculates and shows the final result of your expression.
Ans Recalls the result of your last calculation, so you can reuse it in a new expression.

3. Scientific & Trigonometric Functions

ButtonWhat it does
sin cos tanSHIFT → sin⁻¹ / cos⁻¹ / tan⁻¹ Trigonometric functions (sine, cosine, tangent). Press SHIFT first to get the inverse functions (arcsin, arccos, arctan), which are also directly available as separate asin/acos keys.
hyp Switches sin/cos/tan into their hyperbolic versions (sinh, cosh, tanh) — the HYP indicator lights up on screen.
logSHIFT → 10ʹ Base-10 logarithm. With SHIFT, it becomes 10 raised to a power (the inverse of log).
lnSHIFT → eʹ Natural logarithm (base e). With SHIFT, it becomes e raised to a power.
π   e Instantly inserts the constants pi (3.14159…) and Euler's number e (2.71828…).
√SHIFT → x² Square root. With SHIFT, squares the number instead (x²). x² is also its own direct key.
x³SHIFT → ∛ Cubes the number (x³). With SHIFT, gives the cube root instead.
xʸSHIFT → x√ Raises a number to any power you type (e.g. 2^5). With SHIFT, calculates the nth-root the other way round.
ⁿ√ (nrt) Calculates the nth root of a number directly (e.g. cube root, 4th root, etc.).
x²SHIFT → x! Squares a number. With SHIFT, calculates the factorial (x!) instead — e.g. 5! = 120.
abs Gives the absolute (positive) value of a number, ignoring its sign.
% Percentage calculations — turns a number into a percentage or applies a percent operation directly.
EXP Enters scientific notation quickly — lets you type a number like 5 EXP 3 to mean 5×10³.
×10ʸ Shortcut to multiply the current number by 10 raised to a power you choose — handy for scientific notation.
ENG Switches the displayed result into engineering notation (powers of 10 in steps of 3), commonly used in physics and engineering.
∫ Opens integral calculation input, for definite integrals in calculus.
S⇔D Toggles the displayed answer between fraction form and decimal form.
CALC Used together with ALPHA to evaluate an expression containing a variable (like x) after you enter a value for it.

4. Memory Keys

ButtonWhat it does
M+SHIFT → M− Adds the current result to the calculator's memory. With SHIFT, subtracts it from memory instead. The "M" indicator lights up on screen once memory holds a value.
MR Memory Recall — brings back whatever value is stored in memory.
MC Memory Clear — wipes the stored memory value back to zero.
RCL Recalls the value stored in a specific variable (used together with ALPHA and a letter, e.g. A, B, C).

5. Display Indicators

At the top of the calculator screen, small labels light up to tell you the current status:

  • DEG — angles are being calculated in degrees (this can be changed to radians/gradians from MODE).
  • SHIFT — SHIFT is active; the next key press will use its upper function.
  • ALPHA — ALPHA is active; the next key press will input a letter/variable.
  • HYP — hyperbolic trig mode is active for sin/cos/tan.
  • M — a value is currently stored in memory.
  • READY — the calculator is idle and ready for your next input.
Beyond the calculator: Calvo also has dedicated tabs at the top for Formulas, Past Papers, History, Unit Convert, Percentage/GPA, AI Solver, Quiz, Graph, Equations, Matrix, Programmer, Statistics, Subject Tools and a Study Timer — each works like its own mini-tool, just tap the tab to switch.
