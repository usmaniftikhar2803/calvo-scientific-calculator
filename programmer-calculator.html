Programmer Calculator

By Hafiz Muhammad Usman · Last updated 1 November 2026 · BIN, OCT, DEC, HEX and bitwise tools

Programmer mode is for computer science students and anyone working with number bases and bits. Type a value in any base and see it in binary, octal, decimal and hexadecimal at the same time, then apply bitwise operations to it.

You can set the bit width to 8, 16 or 32 bits, which matters for results such as two's complement and overflow.

What it can do

  • Base conversion: BIN, OCT, DEC and HEX views, plus a custom base.
  • Bitwise operations: AND, OR, XOR, NAND, NOR, XNOR, NOT, left and right shifts, rotate left and right, and MOD.
  • Single-bit control: set, clear, toggle or test a bit at a chosen position.
  • More bit tools: bit count, two's complement, GCD and LCM, ASCII, byte swap, Hamming distance, Gray code, parity, bit reverse, leading and trailing zeros, sign extension and next power of 2.

How to use it

  1. Choose the bit width (8, 16 or 32).
  2. Enter a value in the base you have and read the other bases.
  3. Pick an operation, enter the second value if needed, and read the result.
  4. Use the bit tools for tasks such as counting set bits or finding two's complement.

Bitwise results for 12 and 10

In binary, 12 is 1100 and 10 is 1010. 12 AND 10 = 1000 = 8. 12 OR 10 = 1110 = 14. 12 XOR 10 = 0110 = 6.

Two's complement of 5 in 8 bits: 5 is 00000101, flip the bits to 11111010 and add 1 to get 11111011, which is 0xFB and represents −5.

Tips for better results

  • Always check the bit width. The same operation can give different results at 8 and 32 bits.
  • Hex digits map to 4 bits each, which makes hex a compact way to read binary.

Frequently asked questions

What is two's complement?

It is the usual way computers store negative integers: invert the bits and add one.

Does it handle very large numbers?

It works within the selected bit width, up to 32 bits.

Will it help with my computer science course?

It is useful for number systems, logic and low-level topics. Pair it with the truth table and K-map tool for logic gates.
