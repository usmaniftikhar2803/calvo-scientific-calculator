About these Process Costing formulas

Process costing is used when units flow continuously through one or more processes, such as in chemicals, textiles or food. Costs are collected for each process and divided by the units produced, with special treatment for units lost in the process.

Two ideas drive most problems. First, normal loss is an expected cost of production, so it is valued at scrap value and its cost is spread over the good units. Second, abnormal loss and abnormal gain are valued at the same cost per unit as good output.

How to use these formulas

  • Start with a units statement: input, normal loss, actual output and the difference, which is abnormal loss or gain.
  • Compute the cost per unit on expected output: (total cost − scrap value of normal loss) / (input − normal loss).
  • Value good output, abnormal loss and abnormal gain at that cost per unit, then check that the total equals the cost to account for.

Worked example

Question. A process receives 1,000 units. Total process cost is Rs. 45,500. Normal loss is 10% of input and can be sold for Rs. 5 per unit. Actual output is 880 units.

Normal loss = 1,000 × 10% = 100 units, with scrap value 100 × 5 = Rs. 500.

Cost per unit = (45,500 − 500) / (1000 − 100) = Rs. 50.

Actual loss = 1000 − 880 = 120 units, so abnormal loss = 120 − 100 = 20 units, valued at 20 × 50 = Rs. 1,000.

Good output = 880 × 50 = Rs. 44,000.

Check: 44,000 + 1,000 + 500 = Rs. 45,500, which equals the total cost.

Common mistakes

  • Dividing by total input instead of input less normal loss when computing the cost per unit.
  • Valuing normal loss at cost instead of scrap value.
  • Loading abnormal loss onto good output. Abnormal loss is valued at the process cost per unit, but it is taken out of the process account and written off to the costing profit and loss account.

FAQ

What is the difference between normal and abnormal loss?

Normal loss is the loss expected in the process and is absorbed into the cost of good output. Abnormal loss is any loss above that level, and is treated as a separate cost rather than part of product cost.

What is the difference between FIFO and weighted average equivalent units?

Weighted average treats opening work in progress as if it were started in the current period. FIFO separates the work done on opening WIP in earlier periods, so it measures only the work done in the current period.

What is an equivalent unit?

The number of fully completed units that the work done on partly finished units is equal to. For example, 100 units that are 40% complete are 40 equivalent units.
