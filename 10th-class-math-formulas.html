Algebra (37)

FormulaExpression
Quadratic Formulax = (-b ± √(b² - 4ac)) / 2a
مساوات ax² + bx + c = 0 کے جذر (roots) نکالنے کا کلیہ۔ پہلے مساوات کو معیاری شکل میں لکھیں تاکہ a، b اور c صحیح ملیں۔ ± کا مطلب ہے دو جذر ملتے ہیں۔
DiscriminantD = b² - 4ac
مبین (D = b² − 4ac): D > 0 ہو تو دو مختلف حقیقی جذر، D = 0 ہو تو دو برابر حقیقی جذر، اور D < 0 ہو تو جذر مخلوط (complex) ہوتے ہیں۔
Sum of Rootsα + β = -b/a
دو درجی مساوات کے جذروں کا مجموعہ α + β = −b/a ہوتا ہے۔ جذر نکالے بغیر جواب ملتا ہے۔
Product of Rootsαβ = c/a
دو درجی مساوات کے جذروں کا حاصلِ ضرب αβ = c/a ہوتا ہے۔
(a + b)²a² + 2ab + b²
مجموعے کا مربع: پہلے کا مربع + دوگنا حاصلِ ضرب + دوسرے کا مربع۔ درمیانی جزو 2ab ہوتا ہے، اسے بھولنا عام غلطی ہے۔
(a - b)²a² - 2ab + b²
فرق کا مربع: پہلے کا مربع − دوگنا حاصلِ ضرب + دوسرے کا مربع۔ آخری جزو ہمیشہ مثبت ہوتا ہے۔
a² - b²(a + b)(a - b)
مربعوں کا فرق = (a + b)(a − b)۔ فیکٹر بنانے اور جذر ناطق بنانے (rationalization) میں بار بار آتا ہے۔
(a + b)³a³ + 3a²b + 3ab² + b³
مجموعے کا مکعب: a³ + 3a²b + 3ab² + b³۔ اسے (a + b)³ = a³ + b³ + 3ab(a + b) بھی لکھ سکتے ہیں۔
a³ + b³(a + b)(a² - ab + b²)
مکعبوں کا مجموعہ = (a + b)(a² − ab + b²)۔ دوسرے قوسین میں درمیانی علامت منفی ہوتی ہے۔
a³ - b³(a - b)(a² + ab + b²)
مکعبوں کا فرق = (a − b)(a² + ab + b²)۔ دوسرے قوسین میں سب علامتیں مثبت ہوتی ہیں۔

Remainder Theoremf(x) ÷ (x-a): remainder = f(a)
باقی کا مسئلہ: کثیر رکنی f(x) کو (x − a) پر تقسیم کریں تو باقی f(a) ہوتا ہے۔ لمبی تقسیم کیے بغیر باقی نکالنے کا تیز طریقہ۔
Factor Theorem(x-a) is a factor of f(x) iff f(a)=0
جزو کا مسئلہ: (x − a) کثیر رکنی f(x) کا جزو تب ہی ہوتا ہے جب f(a) = 0 ہو۔

Geometry (12)

FormulaExpression
Pythagoras Theorema² + b² = c²
مسئلہ فیثاغورث: قائمۃ الزاویہ مثلث میں وتر (hypotenuse) کا مربع باقی دو اضلاع کے مربعوں کے مجموعے کے برابر ہوتا ہے۔ وتر ہمیشہ سب سے لمبا ضلع ہوتا ہے۔
Area of Triangle (Heron's)A = √(s(s-a)(s-b)(s-c))
ہیرون کا کلیہ: تینوں اضلاع معلوم ہوں اور اونچائی نہ ہو تو مثلث کا رقبہ نکالیں۔ پہلے s = (a + b + c)/2 (نصف محیط) نکالیں۔
Area of CircleA = πr²
دائرے کا رقبہ = π × رداس کا مربع۔ رداس دوگنا ہو تو رقبہ چار گنا ہو جاتا ہے۔ قطر دیا ہو تو پہلے r = قطر/2 نکالیں۔

Volume of CylinderV = πr²h

Volume of ConeV = (1/3)πr²h
مخروط کا حجم = ایک تہائی × πr²h، یعنی اسی قاعدے اور اونچائی والے بیلن کا ایک تہائی۔
Surface Area of SphereSA = 4πr²
کرے کا سطحی رقبہ = 4πr²، یعنی بڑے دائرے کے رقبے کا چار گنا۔
Area of TrapeziumA = ½(a+b)h
ذوزنقہ کا رقبہ = ½ × متوازی اضلاع کا مجموعہ × ان کا درمیانی فاصلہ (اونچائی)۔
Area of ParallelogramA = base × height
متوازی الاضلاع کا رقبہ = قاعدہ × عمودی اونچائی (ترچھے ضلع کو نہ لیں)۔
