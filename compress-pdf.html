FAQ

How does this PDF compressor work?

Each page is drawn at a lower resolution, saved as a compressed image and put into a new PDF with the same page size. You can pick a level or set a maximum file size.

Is my PDF uploaded anywhere?

No. The file is processed inside your browser and never sent to a server.

Can I select or copy text in the compressed PDF?

No. Pages become images, so the text cannot be selected, searched or edited. Keep the original file for that. The compressed copy is meant for submitting, printing and sharing.

How do I get a PDF under 1 MB?

Enter 1 MB as the maximum size and tap Compress. Calvo tries stronger settings one by one until the file fits, or tells you it could not.

Why is my compressed file not smaller?

PDFs that are mostly text are already tiny, and turning them into images can make them larger. This tool works best on scanned documents and photo-heavy PDFs.

Can it compress a password-protected PDF?

No. Remove the password first, then compress the file.
